# UH EDDS/PAA Studio

Двусторонний конвертер текстур для сообщества DayZ / Arma.

## Что это

**UH EDDS/PAA Studio** — удобный инструмент для конвертации текстур между форматами,
которые используются в проектах на движках Real Virtuality и Enfusion:

- **PNG / JPG / JPEG / TGA / BMP** ⇄ **DDS (.edds)**
- **PNG / JPG / JPEG / TGA / BMP** → **PAA** (через ImageToPAA)

Инструмент создан для мододелов и художников, работающих с текстурами
для игр Bohemia Interactive.

---

## Возможности

- Пакетная конвертация — сразу несколько файлов, с прогрессом по каждому.
- Мип-мапы — от 0 до 8 дополнительных уровней (полное качество базового сохраняется).
- Сжатие **DXT1 (BC1)** и **DXT5 (BC3)** — уменьшает размер в 4–8 раз.
- Нормализация размеров — приведение к степени 2, кратности 4 или заданным W×H.
- Профили конвертации — сохраняй и переиспользуй любимые наборы настроек.
- Просмотр изображений — зум, панорама, листание прямо в приложении.
- Тёмная и светлая темы.
- 10 языков интерфейса: русский, английский, упрощённый и традиционный китайский,
  испанский, немецкий, французский, польский, японский, корейский.
- Drag & drop — файлы можно бросать прямо в окно.
- Системный трей, уведомления, автосохранение настроек.
